# SunliteQLC — нативный Mac-клиент в стиле Sunlite Suite 2, управляющий QLC+

## Что это

Нативное SwiftUI-приложение для macOS, визуально приближенное к интерфейсу
Sunlite Suite 2: ribbon-тулбар, левая панель Pages, блок Color Mixing с
круглым цветовым колесом, кнопки сцен с цветовой кодировкой (жёлтый/красный/
синий). Управление светом идёт через QLC+ по WebSocket — QLC+ транслирует
команды на физический DMX-выход.

## ⚠️ Важно: что подтверждено, а что нет

**Подтверждено** из официальных обучающих видео и руководства Nicolaudie
(разобрано через поиск и просмотр видео, без доступа к живой программе):
- Светлая металлическая Aero-тема (НЕ тёмная — это исправление по сравнению
  с первой версией), оранжевый акцент `#F37021`.
- Ribbon-тулбар с вкладками Controller/Page/Button и круглой App-кнопкой.
- Левая панель Pages с деревом страниц (_MASTER со звездой + пользовательские).
- Цвета кнопок: **Scenes — жёлтые, Switches — красные, Cycles — синие**
  (дословно из официального руководства).
- Блок Color Mixing: круглое HSV цветовое колесо + вертикальный слайдер
  яркости + сетка быстрых цветов + числовые поля RGB/CMY.

**НЕ подтверждено** (сделано по аналогии/приближённо, т.к. нет доступа к
точным пикселям самой программы):

## Протокол QLC+ — всё ещё требует проверки

Формат команды `CH|channel|value` не проверен живьём на твоей версии QLC+.
Перед использованием: открой Virtual Console QLC+ в браузере (Operate-режим,
порт 9999 по умолчанию), через инспектор разработчика (Network → WS)
посмотри реальные фреймы при движении слайдера и сравни с тем, что ожидает
`QLCPlusClient.swift`. При несовпадении правь только этот файл — остальной
код не завязан на протокол.

## Сборка через GitHub Actions (без своего Xcode)

В проекте есть `.github/workflows/build.yml` — он собирает приложение
автоматически на настоящей macOS-машине GitHub (`macos-14` runner), так что
результат — это честная компиляция настоящим Swift-компилятором Apple, а не
приближённая проверка из песочницы.

**Шаг 1 — создать репозиторий на GitHub**
Зайди на github.com → New repository → дай имя (например `SunliteQLC`) →
оставь его пустым (без README/.gitignore — они уже есть в проекте).

**Шаг 2 — залить проект**
В терминале, в папке с распакованным проектом:
```
cd SunliteQLC
git remote add origin https://github.com/<твой-юзернейм>/<имя-репозитория>.git
git branch -M main
git push -u origin main
```
(git-репозиторий и первый коммит уже сделаны — просто подключи origin и запушь).

**Шаг 3 — дождаться сборки**
После пуша открой вкладку **Actions** в репозитории на GitHub — там
автоматически запустится workflow "Build macOS App". Сборка занимает
несколько минут.

**Шаг 4 — скачать собранное приложение**
Когда workflow завершится зелёной галочкой, зайди в этот прогон → в самом
низу страницы будет раздел **Artifacts** с двумя файлами:
- `SunliteQLC-macOS-app` — готовый `.app`-бандл, можно скачать, разархивировать
  и запустить на Mac.
- `SunliteQLC-binary` — просто исполняемый файл без бандла (на случай отладки).

Так как приложение не подписано сертификатом разработчика Apple, при первом
запуске `.app` macOS скорее всего заблокирует его (Gatekeeper). Нужно будет
правым кликом → Open, либо снять блокировку командой:
```
xattr -cr SunliteQLC.app
```

**Если сборка в Actions упадёт с ошибкой** — зайди в лог шага "Build (release)"
и пришли мне текст ошибки, поправим конкретное место в коде.

## Сборка локально на Mac (альтернатива)

```
cd SunliteQLC
swift build -c release
swift run
```
Либо открой `Package.swift` в Xcode (File → Open) и запусти схему
"SunliteQLC" → macOS (⌘R).

## Структура проекта

- `SunliteTheme.swift` — палитра цветов (светлая металлическая тема + оранжевый акцент).
- `RibbonToolbar.swift` — верхняя ribbon-панель (App-кнопка, вкладки, иконки Dimmer/Blackout/Log).
- `PagesPanel.swift` — левая панель со списком страниц приборов.
- `ColorWheelView.swift` — круглое цветовое колесо (Color Mixing).
- `SceneButtonView.swift` — кнопка сцены/switch/cycle с цветовой кодировкой.
- `ChannelFaderView.swift` — фейдер одного DMX-канала.
- `Models.swift` — страницы приборов, сцены, персистентность (JSON в Application Support).
- `QLCPlusClient.swift` — WebSocket-клиент QLC+.
- `App.swift` / `ContentView.swift` — точка входа и сборка главного окна.

## Чего пока нет

- Редактор страниц/приборов (добавление новых Page, патчинг каналов на
  конкретный прибор) — страницы сейчас заданы захардкоженным списком в
  `Models.swift`.
- Таб "Page"/"Button" в ribbon — переключаются, но пока не меняют контент
  (контент работы над ними — следующие шаги плана).
- Cycles как реальные тайм-линии (сейчас это просто ещё один цвет кнопки
  сцены, без шагов/таймингов).
- 3D-визуализатор (Easy View 3D).

Следующие шаги — по мере того, как будем проходить фазы плана, этот список
будет сокращаться.
